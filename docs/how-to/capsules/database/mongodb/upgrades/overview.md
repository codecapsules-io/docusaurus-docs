# Upgrade Your MongoDB Major Version

Major version upgrades must be done one step at a time on **Dedicated** clusters. Select the guide that matches your current and target versions:

- [7.0 to 8.0](/how-to/capsules/database/mongodb/upgrades/7-0-to-8-0/) — upgrade from MongoDB 7.0 to 8.0

See [MongoDB Versions](/reference/capsules/database/mongodb/versions/) for supported versions and general upgrade requirements.
