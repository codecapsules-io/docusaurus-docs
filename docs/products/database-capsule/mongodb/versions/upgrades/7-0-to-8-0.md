# 7.0 to 8.0

This guide covers upgrading a Dedicated MongoDB Capsule from **7.0** to **8.0**.

## Before You Begin

1. **Take a backup.** Create a [manual backup](/products/database-capsule/mongodb/backups/) before changing the MongoDB version.
2. **Plan for brief disruption.** Code Capsules applies the new version on MongoDB Atlas while your capsule status shows **Updating**. Your applications may experience short connection interruptions during the rollout.

## Change the Version

1. Open your MongoDB Capsule dashboard.
2. Go to the **Config** tab.
3. In the **MongoDB Configuration** section, click **Edit**, select **8.0**, and save.
4. Confirm the upgrade when prompted.

![MongoDB Capsule Config tab with version set to 8.0](/gitbook-assets/products/database-capsule/config/mongodb-version-upgrade.png)

Wait until the capsule reports as **Running** and the new version is fully applied before making further changes.

## After Upgrading

- Verify application connectivity against MongoDB 8.0.
- Re-run `db.version()` to confirm the expected version is active.
- Review application logs for driver compatibility or query errors.

Review the [MongoDB 8.0 release notes](https://www.mongodb.com/docs/manual/release-notes/8.0/) for compatibility changes that may affect your application.
