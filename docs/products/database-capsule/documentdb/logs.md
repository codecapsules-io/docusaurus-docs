# Logs

View DocumentDB Capsule logs to monitor activity and debug issues.

## System logs

Open the **Logs** tab to view system logs for your capsule. When running multiple replicas, use the replica selector in the log viewer to filter output from a specific instance.

## Access logs

DocumentDB Capsules do not support public access or custom domains, so the **Access** tab is not available.

Logs are retained for a limited period.
