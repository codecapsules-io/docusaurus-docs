# 5.7 to 8.0

This guide covers upgrading a MySQL Capsule from **5.7** to **8.0**.

## Before You Begin

1. **Take a backup.** Create a [manual backup](/products/database-capsule/mysql/backups/) before changing the MySQL version.
2. **Plan for brief disruption.** Code Capsules rolls out the new version instance by instance. Your applications may experience short connection interruptions during the rollout.

## Change the Version

1. Open your MySQL Capsule dashboard.
2. Go to the **Config** tab.
3. In the **MySQL Configuration** section, click **Edit**, and select "Upgrade to Mysql 8.0".

![MySQL Capsule Config tab with Upgrade to Mysql 8.0 option](/gitbook-assets/products/database-capsule/config/mysql-config-edit.png)

Wait until the Capsule reports as ready and the new version is fully applied before running further changes. Check the [Logs](/products/database-capsule/mysql/logs/) for rollout details.

## After Upgrading

- Verify application connectivity against MySQL 8.0.
- Re-run `SELECT VERSION();` to confirm the expected version is active.
- Review application logs for authentication or SQL compatibility errors.

Review the [MySQL 8.0 upgrade documentation](https://dev.mysql.com/doc/refman/8.0/en/upgrading.html) for SQL and configuration changes that may affect your application.
