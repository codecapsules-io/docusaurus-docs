# Everything About Hosting WordPress

Host managed WordPress on Code Capsules, deployed either as a default install or from your own Git repository. A WordPress Capsule pairs with its own MySQL Data Capsule and Persistent Storage Capsule, and is configured independently through environment variables.

- [Build and Deploy](/products/wordpress-capsule/deploy/) — default install or Git Managed deployment
- [Multi-Instance Content Library](/products/wordpress-capsule/multi-instance-content-library/) — govern a shared plugin/theme codebase centrally and deploy it to many branded WordPress instances
- [Configure](/products/wordpress-capsule/configure/) — database connection, storage, PHP settings, and all environment variables
- [Routing](/products/wordpress-capsule/routing/) — how requests are routed through nginx and how to customise it
- [Caching](/products/wordpress-capsule/caching/) — the built-in page cache
- [Performance](/products/wordpress-capsule/performance/) — PHP, OPcache, and PHP-FPM tuning
- [Security](/products/wordpress-capsule/security/) — built-in security features and how to configure them
- [Cron](/products/wordpress-capsule/cron/) — scheduled WordPress tasks
- [Scale](/products/wordpress-capsule/scale/) — allocate more CPU and memory as traffic grows
- [Backups](/products/wordpress-capsule/backups/) — back up your content and database
- [Monitor](/products/wordpress-capsule/monitor/) — Prometheus metrics for nginx, PHP-FPM, and WordPress health
- [Logs](/products/wordpress-capsule/logs/) — PHP and web-server activity logs
- [Alerting](/products/alerting/) — set up notifications for capsule events
