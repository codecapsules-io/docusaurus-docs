# What You Need Before Installing the CLI

To access services provided via the Code Capsules CLI, you are required to have a registered account on [Code Capsules](https://app.codecapsules.io/).

If you have not used Code Capsules before, we recommend reading our documentation [introducing the platform](/explanation/platform/what-is-code-capsules/), and setting up your first [Team](/explanation/platform/teams/what-is-a-team/), [Space](/explanation/platform/spaces/what-is-a-space/) and [Capsule](/explanation/platform/capsules/what-is-a-capsule/) before using the CLI.



## Next Steps

Once you are set up and comfortable with the Code Capsules platform, you are ready to [install the CLI](/how-to/cli/readme/getting-started/installation-and-usage/).
