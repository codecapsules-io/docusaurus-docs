# Deploy Your First App

Code Capsules is a platform-as-a-service (PaaS) for deploying full-stack apps, databases, containers, and AI agents. Connect a GitHub repository and Code Capsules builds, deploys, and hosts your project, then redeploys it automatically on every push, with no servers to configure or maintain. These docs take you from your first deployment to platform reference, product guides, and hands-on tutorials.
