Big updates across logging, storage, monitoring and scaling.

### New

- **A new logging experience.** A cleaner logging UI, logs filtered by replica for horizontally scaled workloads, much faster querying and searching, real-time logs over websockets, date and time filters, downloads in JSON, text or CSV, and a full-screen mode. Log retention by time and size is in beta.
- **Flexible backup schedules.** Back up daily, weekly or monthly, across Storage, MySQL, PostgreSQL and MongoDB.
- **Independent CPU and RAM scaling** (Internal Developer Platform customers). Scale CPU and RAM separately, for example high CPU with low RAM.

### Improved

- **Logging for Internal Developer Platform customers.** Better backend performance and stability, which lowers infrastructure costs, plus updated dependencies and security patches across the logging stack.
- **Storage management** (Internal Developer Platform customers). Smarter handling of storage and database workloads, and automatic self-healing for horizontally scaled workloads during restarts.
- **Monitoring** (Internal Developer Platform customers). An enhanced monitoring stack with advanced alerting and integrations, custom dashboards and reporting across infrastructure, platform and applications, and support for custom metrics.
- **Capsule state management.** Groundwork for real-time capsule status updates over websockets.
