### New

- **AI Agent Capsules.** [Build and deploy your LangChain-based agents](/products/agent-capsule/deploy/).
- **Deployment strategies.** Choose between a rolling update or re-create, which starts the new instance regardless of the previous instance shutting down.
- **GPU workloads.** Private enterprise customers can flag workloads to run on GPU compute.

### Improved

- The builds UI now shows how long each build took, plus its branch and commit hash.
- Successful automatic builds link to the Git diff between the previous and current build.
- More accurate metrics, and better graphs for multiple replicas across capsule types.
- Faster egress networking.
- Better horizontal scaling for PostgreSQL Capsules.
- Changing config such as the port or environment variables now restarts the capsule instead of rebuilding it.
- General bug fixes and improvements across the site.

### Fixed

- Instance restarts no longer happen twice.
