Released 9 November 2026.

### New

- **Redis persistence.** Turn persistence on when you create a Redis Capsule, or later from its settings. You can now see how much disk Redis is using, and the dashboard checks that it's safe before you reduce RAM. See the [Redis Capsule docs](/products/database-capsule/redis/deploy/).
- **Choose your WordPress PHP version.** Pick PHP 8.3, 8.4 or 8.5 for WordPress Capsules. WordPress Capsules are also out of beta. See [Configure a WordPress Capsule](/products/wordpress-capsule/configure/).
- **SFTP for Storage Capsules.** Storage Capsules now support SFTP alongside WebDAV, sharing the same toggle and login. See [Configure a Storage Capsule](/products/storage-capsule/configure/).

### Improved

- **Faster dashboard.** Capsule detail and scale pages load faster.
- **New loading screen.**

### Fixed

- **Frontend and static sites.** Fixes for routing and custom domains, plus a toggle for the default domain.
- **Dashboard.** The capsule status filter works again.
