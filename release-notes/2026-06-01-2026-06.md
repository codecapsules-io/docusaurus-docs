### New

- **MongoDB Capsules.** Create a MongoDB Atlas instance through Code Capsules. See [Deploy a MongoDB Capsule](/products/database-capsule/mongodb/deploy/).
- **Cancel builds.** Stop a build you started by accident, make your changes, and rebuild when you're ready.
- **Delete builds.** Choose which builds to keep, so your most stable build isn't removed automatically when you reach your build limit.
- **View deleted builds.**

### Improved

- CLI improvements.
- General bug fixes and improvements.

### Fixed

- Adding a card no longer returns a false "failed" status when charging the test amount.
- You're no longer logged out at random when you refresh the site.
- MySQL logs are no longer cluttered by a message that repeated every 1 to 2 milliseconds.

:::info

The CLI improvements require upgrading to the latest version. Older versions of the CLI no longer work with this release.

```sh
npm i -g @codecapsules/cli@latest --force
```

:::
