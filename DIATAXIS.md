# Diátaxis Classification

Every doc in `docs/` and `release-notes/` classified by content type. Total: 234 docs.

The first four types are the Diátaxis types. `hub`, `overview` and `release-notes` cover pages Diátaxis does not.

| Type | Count | Meaning |
|---|---|---|
| `tutorial` | 17 | Learning-oriented: build something end to end. |
| `how-to` | 144 | Task-oriented: steps to achieve one goal. |
| `reference` | 20 | Lookup facts: options, limits, versions, API, commands. |
| `explanation` | 12 | Understanding-oriented: what it is and why. |
| `hub` | 25 | Navigation page that links to children; no content of its own (outside Diátaxis). |
| `overview` | 7 | Product positioning / marketing page (outside Diátaxis). |
| `release-notes` | 9 | Dated changelog (outside Diátaxis). |
